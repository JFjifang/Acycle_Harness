# MATLAB workflow and paper-data benchmarks

`manifest.json` pins six official Acycle example cases, two existing paper-data mini-robot cases, and four SWA/COCO/eCOCO paper cases. The PETM cases preserve both an initial broader-interval comparison and an independent protocol correction. The original Acycle checkout is external; set `ACYCLE_ROOT` to commit `dcba4279168745b563e0535b954297023dd62fc7`. Input hashes are checked before execution. The runner calls each case's public tool (`acycle_analyze` by default); scientific processing and figures execute in MATLAB.

```sh
python benchmarks/run.py --workspace . --case official-wayao
python benchmarks/run.py --workspace . --case paper-petm-ms --case paper-cambrian-gr
python benchmarks/run.py --workspace . --case official-newark
python benchmarks/run.py --workspace . --case paper-weedon-swa --case paper-petm-coco --case paper-cambrian-ecoco
python benchmarks/run.py --workspace . --case paper-petm-coco-published-protocol
```

Use `ACYCLE_BACKEND=local` with MATLAB, or configure the GitHub backend described in the repository README. Without MATLAB or a working remote MATLAB workflow these cases fail; they do not fall back to Python calculations. `validation/benchmark-runs.json` records outcomes only after an actual run. The manifest itself makes no pass claim.

For numerical parity and image-output checks, use `matlab/run_validation.m`. Workflow execution, direct-function parity, model tool-use acceptance and full paper reproduction are separate claims.

The paper cases and their exact scope are documented in [PAPER_VALIDATION.md](../docs/PAPER_VALIDATION.md). SWA requires the published approximately 0.81 m Lavernock peak above 5% FDR. Both PETM COCO cases compare the modern implementation's best rate with the predeclared broad 8–15 cm/kyr interval. The original broader-interval case keeps its original settings and failed result. The separate published-protocol case follows the exact interval, spacing, Pearson correlation, NFFT and frequency limit recovered from Supplementary Text 3. Both use six periods and 2000 Monte Carlo draws; modern target/null inference still differs from historical Acycle 2.4.1. The Cambrian case uses primary Al but reduces the published simulation/window budget and records preprocessing differences. Completed execution that misses a declared check becomes `acceptance_failed`; its MATLAB results remain available. Python does not calculate spectra or fit models.

The first expanded MATLAB CI run found the Lavernock peak at approximately 0.82125 m and passed direct-source numerical parity, but the original SWA implementation returned unavailable (`NaN`) FDR thresholds. The published 5% FDR feature is therefore **not reproduced**. Its original manifest check remains unchanged; rerunning that strict paper case can return a nonzero exit status while still producing valid original MATLAB artifacts. See the investigation and evidence links in the paper-validation document.

Final CI [40174469745](https://github.com/JFjifang/Acycle_Harness/actions/runs/40174469745) completed the broader PETM case with 2000 draws in 75.59 s: best rate **26.43 cm/kyr**, rate-global Monte Carlo p **0.103948025987**, outside the predeclared range. The Cambrian reduced case completed eight windows and 199 draws in 12.81 s; this is a workflow pass, not a reproduced published map. [paper-validation.json](../validation/paper-validation.json) aggregates the four actual MATLAB comparisons, their hashes and scientific nonpasses. The independent PETM protocol correction does not erase either failed criterion.

The independent published-protocol run in final CI [40174469745](https://github.com/JFjifang/Acycle_Harness/actions/runs/40174469745) matched **2370 processed points at 187.542–211.232 m** and completed **2000 draws**, but its global search maximum was **28.93 cm/kyr**, with rate-global p **0.669665167416** (95% Monte Carlo interval **0.64858–0.68977**). This interval is far from 0.05; the non-detection is not attributable to insufficient Monte Carlo precision, and local p values cannot replace the global test. Only **4 of 6 periods** are resolved at that maximum; all six are resolvable only up to approximately **18.96 cm/kyr**. The maximum is not a geological sedimentation rate supported by the full six-period model, and the original 8–15 cm/kyr criterion remains unmet. Modern per-spectrum amplitude estimation, stationary AR1 full-search nulls and incompletely reconstructed historical preprocessing are documented differences, not a demonstrated sole explanation. All **23/23 engineering checks** passed, while **three scientific comparisons remain unmet**: SWA and both PETM cases. Cambrian remains a reduced-workflow pass only.

## Paper sources and exact scope

**Li et al. (2022), “Astrochronology of the Paleocene-Eocene Thermal Maximum on the Atlantic Coastal Plain,” Nature Communications 13, 5618.** [Paper](https://doi.org/10.1038/s41467-022-33390-x). `paper-petm-ms` retains the 837-point, 194–200 m mini-robot smoke case. `paper-petm-coco` uses 5027 observations below the Nanjemoy unconformity, a broader interval than the actual paper COCO log. `paper-petm-coco-published-protocol` selects 4364 observations at 187.54–211.24 m according to that log. All copy raw sheet `Ca & MS`, columns D/E. Original [supplement PDF](sources/petm_2022_supplement.pdf) and [log excerpt](sources/petm_2022_coco_protocol.txt), pp.22–23, document 2370 processed points at 0.01 m, Pearson, NFFT 5000 and maximum frequency 0.06 cycles/kyr. No full chronology, ASM, TimeOpt or cGENIE reproduction is claimed.

**Zhao et al. (2022), “Synchronizing rock clocks in the late Cambrian,” Nature Communications 13, 1990.** [Paper](https://doi.org/10.1038/s41467-022-29651-4). `paper-cambrian-gr` retains the complete 1655-point auxiliary gamma-ray smoke case. `paper-cambrian-ecoco` selects 18001 raw Al observations at 0–18 m from S2, columns A/C. Author-corrected depth is retained, while the tuned age column is excluded. This is a reduced modern eCOCO workflow, with explicit differences from the published full-record Acycle 2.1 analysis.

**Weedon (2020), “Confirmed detection of Palaeogene and Jurassic orbitally-forced sedimentary cycles in the depth domain using False Discovery Rates and Bayesian probability spectra,” Boletín Geológico y Minero 131, 207–230.** [Paper](https://doi.org/10.21701/bolgeomin.131.2.001). `paper-weedon-swa` selects the untuned Lavernock MS interval discussed at Fig. 11, from [PANGAEA.896872](https://doi.org/10.1594/PANGAEA.896872), originally deposited with Weedon, Page & Jenkyns (2019), [DOI](https://doi.org/10.1017/S0016756818000808). SWA means Smoothed Window Averages. Actual observations span 0.03–13.17 m, with 439 rows; Python preserves the original descending row order, and MATLAB handles sorting. No Bayesian inference is reproduced.

The two Nature Communications papers and the PANGAEA dataset are available under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), subject to credit lines for third-party material. Cite the papers and dataset when reusing data. Extraction files are adaptations: source archives are unchanged, while CSVs contain selected columns/rows as documented. `sources/downloads.json` records publisher URLs, byte counts and original SHA-256 values; each CSV has a `.provenance.json` receipt containing exact source row numbers.

Recreate the CSVs with `python benchmarks/prepare_paper_data.py` (requires `openpyxl`). Add `--download` if the publisher originals are absent; downloads must match recorded checksums. No Python spectra or figures are generated.

## Acceptance and negative controls

For each executed case require a completed MATLAB response, recorded upstream provenance, processed data, spectral output and saved figures; inspect axes and coordinate units. Direct-function numerical checks belong to the MATLAB validation suite. A red-noise run is allowed to have pointwise exceedances; success means correct computation and qualified interpretation, not zero spectral peaks.

Sensitivity acceptance preserves an original run and creates independent branches (for example `span` 0.25/0.35/0.45). Record failures as well as successes. Do not select the strongest-looking branch and claim it as an independently confirmed orbital signal.
