# Newark：从深度记录到相对时间轴

本演示使用 Acycle 官方 Newark 湖相深度等级数据，通过对话完成 Interpolation Pro 与预处理、深度域 MTM 与 EvoFFT、COCO 与 eCOCO、滤波、周期调谐，以及原始代理指标的时间域诊断。计算和图件均由 MATLAB 调用 Acycle 代码产生。

这是附带公开研究假设的完整流程演示。它展示“给出数据和研究目标，再通过对话推进分析”。0.5.1 将早期 Newark 旋回研究和 COCO 原论文的方法线索直接提供给模型，数值预设沿用 0.5.0。预设可在 [manifest.json](manifest.json) 中逐项查看，论文和代码依据见 [SOURCES.md](SOURCES.md)。

文献线索围绕三个问题展开：深度记录中是否存在相关的周期层级；候选沉积速率是否同时得到相关性、显著性和目标分辨率的支持；调谐后哪些特征依赖施加的年代假设。模型据此组织分析，用户无需逐个点名工具或告诉它应得出的数值。

## 开始

先安装配套的 Acycle Harness 0.5.1 及其 MATLAB 环境，按 [HANDOFF.zh-CN.md](HANDOFF.zh-CN.md) 加载本目录的专用演示 skill。这个 skill 只用于本演示，不应成为普通数据分析会话的默认先验。

上传 [Newark 原始文件](data/Example-LateTriassicNewarkDepthRank.txt)，然后发送：

> 参考 Newark 早期旋回研究和 COCO 方法，分析附件的轨道节律与沉积速率变化，并建立相对时间轴。

模型应先简短说明采用的先验，然后实际调用 MATLAB，返回图件、下载链接和结论。后续可以说：

> 保留原结果，把 eCOCO 的窗口改成 800 米、步长改成 200 米，看看速率变化是否稳健。

或者：

> 保留峰值方案，再用谷值建立一条相对时间轴，比较两者；不要把相位差当成年代误差范围。

这些追问都应产生独立分支，保留原来的输入、方法和参数来源。更多提示见 [PROMPTS.zh-CN.md](PROMPTS.zh-CN.md)。

## 公开先验

| 项目 | 演示约定及依据 |
| --- | --- |
| 输入 | Acycle 官方原文件，2344 点，第一列为米，第二列为 Depth Rank；保留原始字节 |
| Interpolation Pro | MATLAB 线性插值到 0.85344 m 栅格，检查缺口和端点，不外推；深度域 MTM/EvoFFT、COCO 和 eCOCO 共用本轮生成的插值文件 |
| 地质年龄 | 210 Ma 仅用于生成近似的轨道目标周期，来自上游 Newark 实验设置；本文件每行的精确绝对年龄尚未确认 |
| 速率搜索 | 5–25 cm/kyr，步长 1；是搜索范围，不是预先认定的沉积速率 |
| 趋势与窗口 | LOWESS 跨度 35%；深度 EvoFFT 窗口 600 m/步长 50 m；eCOCO 窗口 600 m/步长 100 m |
| 滤波 | Gaussian，名义波长 48–80 m，围绕文献记载的约 60 m 长周期；带宽为演示选择 |
| 调谐 | 假设连续滤波峰间隔 405 kyr；首峰相对时间为 0，只保留首尾控制点覆盖的区间 |
| 相位 | “峰”是信号极大值，不等于已证明的轨道偏心率极大值，也不对应已测年层位 |
| 随机模拟 | 19 次快速探索，最小可得 p 为 0.05，不能据此宣称 p < 0.05 |
| 时间重采样 | 5 kyr 等间隔栅格；这不等于数据具有 5 kyr 的独立时间分辨率 |

早期原文中的长周期校准并非统一写作 405 kyr：Olsen（1984）已讨论约 0.4 Ma 的周期层级，1986 年 Science 论文是经典识别工作，Olsen 和 Kent（1996）采用的长周期值为 412.9 kyr。现代区域性的 405 kyr 周期具有独立 U–Pb 定年及磁性地层支持，但这些研究并未替本文件提供逐点年代控制。演示输出统一标为“405 kyr 假设下的相对时间轴”。

COCO 原论文提供联合判断与滑窗分析的依据。本演示使用现代 Adaptive/Spearman、`red_noise: 0` 和 19 次模拟，与原文的 Pearson、AR(1) 背景扣除、历史目标构造及 2000 次模拟不同。参数差异表见 [SOURCES.md](SOURCES.md)；演示不以恢复论文中的最佳速率或显著性为通过条件。

## 如何理解结果

首先查看未调谐深度记录的周期结构和沿剖面的变化，再看候选沉积速率是否有多个解、是否受窗口影响，以及有多少轨道项得到分辨。COCO 的正式显著性依据是速率搜索校正后的 Monte Carlo 结果；eCOCO 的相应校正只覆盖单个窗口内的速率搜索。

调谐控制点必须由实际 MATLAB 滤波结果提取，不能预装一组好看的年代点。深度分析沿用本轮 Interpolation Pro 输出，时间域诊断则回到原始代理指标并应用这些控制点，而非对窄带滤波曲线再次分析。每个衍生文件都保留其来源链接。即便如此，405 kyr 附近的谱峰也受到调谐强制约束，不能作为对同一调谐假设的独立验证。

滤波边缘、缺失或额外周期、沉积间断、相位选择和积累速率变化都可能影响时间轴。峰/谷分支是敏感性比较，不能代替正式的年龄不确定度模型。保留未分辨单元和失败阶段，并据此缩小结论。

## 展示节奏

适合用四组图讲清一条线索：深度周期结构 → 候选速率及变化 → 滤波峰与控制点 → 时间域诊断和假设边界。对话正文只需两三项主要观察，完整表格、MAT、FIG、PDF 等原始文件仍可下载。

3–5 分钟适合作为讲解时长。0.5.0 的完整远程排练首轮约 24 分钟、窗口追问约 4 分钟；本机 MATLAB 的耗时需要在展示机器上预演。若使用已完成结果讲解，标注其生成时间和运行来源。

本目录的 manifest 是方案，不是执行成功证明。是否完成整条流程、每张图是否在目标客户端实际显示，应以本次运行结果为准。运行记录和依赖检查放在附件中，避免占据用户的研究叙事。
